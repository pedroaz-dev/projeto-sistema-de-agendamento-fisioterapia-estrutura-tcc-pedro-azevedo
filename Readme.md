## Como Executar o Projeto

Instruções claras para a banca ou avaliador rodar o projeto localmente.

### Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina as seguintes ferramentas:

- [Git](https://git-scm.com)
- [Node.js](https://nodejs.org) (ou a linguagem utilizada)
- Um SGBD como [MySQL](https://mysql.com)

### Passo a Passo (Exemplo com Node/NPM)

```bash
# 1. Clone este repositório
\$ git clone https://github.com/nome-do-repositorio.git

# 2. Acesse a pasta do projeto no terminal
\$ cd nome-do-repositorio

# 3. Instale as dependências
\$ npm install

# 4. Configure o arquivo de variáveis de ambiente (.env) com as credenciais do banco

# 5. Execute as migrações do banco de dados (se houver)
\$ npm run db:migrate

# 6. Execute a aplicação em modo de desenvolvimento
\$ npm run dev
```

O servidor iniciará na porta `:3000` - acesse <http://localhost:3000>
